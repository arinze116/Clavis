# Clavis brand refresh brief

Status: working design evidence, not a legal-clearance claim.

## Product truth

Clavis is a rule-bound payroll control plane on NEAR Testnet. Owners set policy; a restricted scheduler may request settlement; the contract makes the final decision, moves native NEAR, and records minimised audit evidence.

## Audience and surfaces

- Remote-team owners evaluating payroll controls.
- Workers checking employer decision history.
- Developers, security reviewers, and hackathon judges.
- Web navigation, favicon, Apple touch icon, social card, demo end card, documentation, and monochrome technical contexts.

## Identity requirements

- Communicate bounded authority, dependable settlement, and visible rules.
- Remain recognisable at 16 px without relying on fine internal cuts.
- Avoid generic AI sparkles, orbit motifs, crypto nodes, shields, and decorative complexity.
- Preserve the established ink (`#11130f`), acid (`#c8ff62`), and warm-white (`#f8f8f5`) palette unless testing disproves it.
- Work as a symbol alone and beside the existing Clavis wordmark.

## Concept directions

### A — Keygate

A `C`-shaped key bow joined to a restricted key stem. It connects the Clavis name to limited permissions without using a conventional circular key icon.

### B — Policy gate

Three possible actions meet a hard gate; only the approved middle rail passes through. It directly represents “enough authority to run payroll, no authority to break the rules.”

### C — Verified C

An open `C` interlocks with a decisive check. It emphasizes public verification and successful contract settlement.

## Evaluation

Each direction is tested for product meaning, distinctiveness, silhouette, 16/32/128 px rendering, light/dark/monochrome use, and fit in the current desktop/mobile interface. Creator review is not independent validation.
